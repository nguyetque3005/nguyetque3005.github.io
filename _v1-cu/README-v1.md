# Tiếng Hàn cùng Queenie

Homepage static HTML/CSS/JS theo phong cách:
- Soft pink / blush
- Korean feminine personal brand
- Personal teacher + blog + Korean lifestyle
- Responsive desktop / tablet / mobile
- Scroll reveal
- Mobile navigation
- Active navigation
- Back to top
- Reduced-motion support

## Chạy

Không cần framework.

Cách 1:
Mở trực tiếp `index.html` bằng browser.

Cách 2:
Dùng VS Code Live Server.

Cách 3:
```bash
python3 -m http.server 8000
```
Sau đó mở:
http://localhost:8000

## Cần thay đổi

1. Thay ảnh Unsplash trong `index.html` bằng ảnh thật của Queenie.
2. Thay email:
   `hello@queenie-korean.com`
3. Thay link Instagram / TikTok / YouTube / Facebook.
4. Chỉnh timeline theo thông tin thật.
5. Thay nội dung blog.
6. Có thể đổi màu trong `style.css` ở phần `:root`.
