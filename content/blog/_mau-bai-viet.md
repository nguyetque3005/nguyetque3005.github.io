File này là **bản mẫu**. Tên file bắt đầu bằng dấu gạch dưới `_` nên nó không được đăng lên website.

## Cách viết một bài mới

1. Copy file này, đặt tên mới theo dạng `2026-09-15-ten-bai-viet.md` (không dấu, không khoảng trắng).
2. Sửa phần thông tin ở đầu file (giữa hai dòng `---`).
3. Viết nội dung bên dưới.
4. Chạy `npm run build`.

## Những gì bạn viết được

Chữ **in đậm**, chữ *in nghiêng*, và [chèn liên kết](https://example.com).

> Trích dẫn thì để dấu lớn hơn ở đầu dòng như thế này.

Gạch đầu dòng:

- Ý thứ nhất
- Ý thứ hai

Đánh số:

1. Bước một
2. Bước hai

Chèn ảnh:

![Mô tả ảnh](/assets/images/blog/ten-anh.jpg)
